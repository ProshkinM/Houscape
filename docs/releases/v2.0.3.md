# Houscape v2.0.3

## Stability and performance

- Fixed a crash when switching quickly between the floor-plan editor and device editor.
- Made the editor layout resilient while Home Assistant replaces card elements during view changes.
- Prevented duplicate `ResizeObserver` instances when the editor toolbar is rebuilt.
- Removed a redundant Three.js geometry conversion that produced console warnings and unnecessary allocations.
- Added regression tests for indexed and non-indexed cloud geometry; the complete suite now contains 492 tests.

After updating through HACS, restart Home Assistant and force-refresh the browser with `Ctrl+Shift+R` (`Cmd+Shift+R` on macOS).
